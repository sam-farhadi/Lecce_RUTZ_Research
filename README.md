# RUTZ Index — Master's Thesis Showcase

**Reframing Rural–Urban Transition Zones as Climate Buffers: Morphological and Ecological
Perspectives for Climate Resilience in Lecce, Italy**

MSc thesis, Urban & Regional Planning, Politecnico di Torino (DIST).

This repository holds the public-facing outputs of the thesis:

## [`dashboard/`](./dashboard)

An interactive research dashboard presenting the core empirical outcomes of the RUTZ
Index — a composite instrument classifying Lecce's peri-urban transition zone across an
8,625-cell fishnet grid into a five-class peri-urban gradient and a four-class dominant
ecology typology.

**[View the live dashboard →](https://sam-farhadi.github.io/Lecce_RUTZ_Research/)**

## [`gis-pipeline/`](./gis-pipeline)

Documentation of the ArcGIS Pro Model Builder pipeline and arcpy logic used to derive the
thermal and morphological metrics behind the index.
